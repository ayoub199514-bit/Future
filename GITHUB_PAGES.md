# GitHub Pages quick fix

1. Commit/push the root `index.html`, `config.js`, `.nojekyll`, and the existing folders.
2. In Settings → Pages choose `main` and `/(root)`.
3. Open the Pages URL and verify the heading says **FURI Mining Algeria v4**.
4. If the old v2 page remains, use a hard refresh / private tab after the deployment finishes.
